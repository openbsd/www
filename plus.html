OpenBSD -current Changelog

This selection is intended to include all important and all user-visible changes. For a complete record of all changes, please see the "source-changes" mailing list, called "OpenBSD CVS" in the archives, or use CVS.

Changes made between OpenBSD 8.0 and -current

  • Capped ssh(1) keyboard-interactive devices accepted, to avoid DoS in sshd-auth.
  • Use client source port instead of remote proxy port, to unbreak relayd(8) PROXY sending.
  • Merged fixes for Xserver(1) CVEs.
  • Added cpu scaling and GPIO pin access to the Qualcomm CPUSS Control Processor driver.
  • Automatically load the DTB for Qualcomm-based Thinkpad T14s Gen 7 and Yoga Slim laptops.
  • Correct outgoing record checks in the legacy ssl(8) TLSv1.2 stack.
  • Made rpki-client(8) enforce a single AS identifier in ASPA EE certs.
  • Stopped prepending underscores to symbol names in nlist(3) input.
  • No longer allow TIOCSCTTY, TIOCNOTTY, or TIOCSPGRP on the pty master, avoids incoherent session states.
  • Track age of etherbridge entries in gre(4).
  • Made vmd(8) reject vioblk requests beyond the disk capacity; check alignment.
  • In iked(8): implemented IKEv1 support (experimental).
  • Fixed pf(4) traffic statistics for state created by af-to rules.
  • Fixed pf(4) flush for source tracking rules under NAT.
  • Unlocked KERN_HOSTNAME and KERN_DOMAINNAME sysctl pathsm using mutexes to protect.
  • Made smtpd(8) fail on usernames and passwords that are too long.
  • Properly set smtpd(8) socket lengths when building the various sockaddr structures.
  • Fixed ld.lld(1) .note.gnu.property values in ld -b binary invocations.
  • In pf(4), limit retries to avoid depleted source port pool for NAT starving other packets.
  • Raises the drm(4) gem object size limit from 512M to 1.5G.
  • Added ujoy(4) devices to wscons group, reducing permissions to 440.
  • Multiple bugfixes for amdgpu(4).
  • For SEV-SNP, disabled ipmi(4) on confidential VMs.
  • Added ML-DSA 44 support (based on BoringSSL).
  • For SEV-SNP, added memory clobber to vmgexit() so content not cached across the instruction.
  • Avoid use-after-free in IPv6 duplicate address detection.
  • Stopped checkalias replacing vnodes in vfs.
  • Avoid out-of-bounds wscons(4) array accesses.
  • Stopped ix(4) deallocating rings in DVACT_SUSPEND, reuse them in DVACT_RESUME.
  • Added addresses to smtpd(8) log lines.
  • Fixed rx map leak in em(4).
  • Fix race where tcp(4) syn cache could free a used route.
  • Made rtwn(4) send complete H2C commands to the firmware.
  • Hide ld.so(1) LD_DEBUG support behind a compile-time #ifdel DL_DEBUG; removed other information leaks.
  • Libutil updated to version 23.0.
  • crypto(3) will now reject any v1 CRL's.
  • Made openssl(1) always issue v2 CRLs.
  • Replaced login_fbtab(3) with the wscons(4) group if the users is on the glass console.
  • crypto(3) will now ignore the Netscape certificate type extension.
  • Made openssl(1) always issue v3 x509 certificates.
  • Backported security fixes from zlib 1.4.
  • Securelevel(7) 2 no longer prevents pf(4) ruleset changes.
  • Capped snmpd(8) getbulk max-repetitions to 50.
  • Adapted firmware from rge(4) to work on ure(4) RTL8157 and RTL8159.
  • Updated libexpat to version 2.10.0 for security fixes.
  • Fixed resets on Fujitsu Futro S940.
  • Removed a potential sleep point in the nvme(4) resume path.
  • Avoid using malloc(9) to avoid sleep(3) in DVACT_SUSPEND and DVACT_RESUME.
  • Plugged mbuf leak in inet6(4) forwarding.
  • Add 'Q' flag/key to top(1), show pledge/chroot/unveil usage.
  • Fixed vio(4) control queue handling during reset.
  • Fix mbuf leak in ip(4) rip_output when in_pcbselsrc fails.
  • patch(1) will now abort in fetchname() if out of memory.
  • Fixed rge(4) RTL8125 and RTL8125B TX hangs on short UDP frames.
  • Made aggr(4) balance traffic over ports like trunk(4); improved use of flowids in the TR path.
  • Added sanity check for queue priority assigned to pf(4) state via 'set prio' rule action.
  • Improved malloc(3) canary code to handle more cases.
  • Avoid race condition in pf(4) tcp scrub pf_test_state().
  • Reworked how rtables are allocated and reduce use of RT_TABLEID_MAX by ip(4) and subsystems.

  • rpki-client(8) will now disallow certs with zero serialNumber.

  • Made uhidev(4) reject payloads that exceed their declared input report sizes.
  • Provide flags specify using IPv4 or IPv6 in dbupdate(8), fw_update(8), syspatch(8), and sysupgrade(8).
  • In rpki-client(8), reject URIs with // except at the start of the authority.
  • Activated linker relaxation on riscv64, to let ld.lld(1) rewrite branches.
  • Added ssh(1) -Q addressfamily.
  • Added 'glob' and 'glob ignorecase' matching keywords to relayd.conf(5); made parser more strict.
  • Limit impact of quadratic workload in rpki-client(8) caused by duplicate references from manifests.
