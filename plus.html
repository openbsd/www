OpenBSD -current Changelog

This selection is intended to include all important and all user-visible changes. For a complete record of all changes, please see the "source-changes" mailing list, called "OpenBSD CVS" in the archives, or use CVS.

Changes made between OpenBSD 8.0 and -current

  • Improved apm(8) info for machines without a battery.
  • Fix calculation of i/o size needed to read FSInfo struct in mount_msdos(8).
  • Properly activate aq(4) when detected at boot time.
  • Added RX queues/RSS/TSO support and update microcode for rge(4) RTL8127.
  • Fixed pppoe(4) out-of-bounds memory write, stack disclosure, and SIGSEGV.
  • Added unveil(2) to npppd(8); fixed stack leak.
  • Stopped npppd(8) from allowing a non-privileged process to open any file.
  • Multiple drm(4) bugfixes.
  • Improved mandoc(1) error messages with '-mdoc -T' markdown mode.
  • Updated libexpat to version 2.8.5.
  • Fixed llvm compiler-rt __clear_cache() on mips64.
  • Fix initialisation sequence required by virtio(4) 3.1.1.
  • Fixed uncm(4) link establishment on Pixel 7a.
  • Simplified video(4) kern.video.record logic to avoid bcopy with unchecked parameters.
  • Updated to makedepend(1) 1.0.10.
  • Updated to xserver(1) 21.1.25, libpng(3) 1.6.59, xclipboard(1) 1.1.6, xclock(1) 1.2.1, xfd(1) 1.1.6, xkbprint(1) 1.0.8, xload(1) 1.2.2, xmodmap(1) 1.0.12, xpr(1) 1.2.1, xwininfo(1) 1.1.7.
  • Fixed an off-by-one error in bsd_decompress().
  • Fixed ld.so(1) information leaks with AUX_openbsd_execmode.
  • Made binutils aware of the AUX_openbsd_execmode variable.
  • Cope with dates after 2040 on ADB macppc systems and macppc laptops.
  • Cleanup and refactoring of rc.subr(8).
  • More complete parsing sanity checks in rc.subr(8).
  • If rc.d run script was updated, ensure rc.subr(8) uses original values until restart.
  • unveil(2) and pledge(2) for ypmatch(1), ypwhich(1), and yppoll(8).
  • Avoid infinite loop in pcidump(8) when encountering misbehaving devices.
  • Add extra vmd(8) mmio region, allows i686 linux kernels work with less RAM.
  • unveil(2) and pledge(2) for fgen(1) and ypbind(8).
  • Reworked handling of the rpki-client(8) certificate expire time.
  • Fixed race condition in rc.subr(8).
  • Updated to pkgconf(1) 3.0.8.
  • In pf(4), check AH extension header length.
  • Added mwx(4) driver for Mediatek MT792x wifi devices.
  • Better malloc(3) boundscheck and low-memory behaviour in wsdisplay(4) WSDISPLAYIO_LDFONT.
  • Implemented mwx(4) MT7925 association to open APs in 11a/b/g modes.
  • Add tmux(1) commands to copy mode to select, pipe and open OSC 133 command output.
  • Don't allow mwx(4) deep sleep in ASSOC state, more stable connection and roaming.
  • Added vmd(8) queue size checks and reject malformed descriptor chains.
  • Enabled ssh(1) ssh-mldsa44-ed25519 as an allowed CA signature algorithm.
  • Added truncation detection to the vmd(8) instruction decoder.
  • In pf(4), check extension header length does not exceed packet length.
  • Made mandoc(1) map '\:' to U+200B, to improve html output.
  • Fixed mandoc(1) handling of special character escape sequences used as delimiters.
  • Fixed mandoc(1) rendering of the \l (horizontal line) escape sequence.
  • Made dhcpd(8) siscard packets with unsupported htype's.
  • Show match count in tmux(1) copy mode.
  • Added tmux(1) window-default-command option to override default-command per window.
  • In mandoc(1) '-T utf8' output mode, made '\:' correctly output a line break not a glyph.
  • Implemented mediaopt monitor for MT7925 with mwx(4).
  • Enables urndis(4) in the installer on amd64.
  • Fix refcnt bug in mwx(4) tx path, fixes hangs on MT7921.
  • Added preliminary support of RTL8159 to ure(4).
  • Fixed tmux(1) tty_clamp_area with status lines at the top and a smaller display.
  • Added uncm(4) to i386 GENERIC config, and uncm(4) and urndis(4) to RAMDISK_CD.
  • Fixed mandoc(1) HTML formatter when encountering nonsensical sequence of macros.
  • Enabled uncm(4) in the installer on amd64 (allows firmware-less network installs).
  • Added uncm(4), a driver for USB CDC NCM (i.e. USB phone tethering).
  • Fixed GPIO wakeup masking during suspend.
  • First bits of scan code added for the mwx(4) MT7925 chip.
  • Do not lose a pending pane resize when entering the alternate tmux(1) screen.
  • In tmux(1), adjust widths of a few codepoints incorrectly set to double width.
  • Multiple bugfixes for drm(4), amdgpu(4), inteldrm(4), and radeondrm(4).
  • Further restrict the characters allowed in a ssh(1) command-line-supplied user name.
  • In drm(4), fixed drm_pending_vblank_event leak in error path for out_fence_ptr.
  • Reserve a 16K-byte gap at start swap partitions, for upcoming disklabel changes.
  • In sysv_shm, fixed ordering claim on vm_shm slot.
  • Made mandoc(1) follow groff_mdoc(7) behaviour for width of a .Bl macro.
  • Made rpki-client(8) use SOCK_NONBLOCK where possible; handle errors for fcntl().
  • Improved mandoc(1) section identifier handling.
